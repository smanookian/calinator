Thank you for the review. Calinator (project calinator, number 104932519162) does not use AI or machine learning in any form, so the Limited Use AI/ML restrictions are met:

1. Transfer of user data to third-party AI services: none. Calinator never sends Google user data, or any data derived from it, to an AI service or to any other third party. Data goes only between the user's computer and Google Calendar.

2. Third-party AI integrations: none. Calinator integrates with no AI provider, on any plan or tier.

3. Multi-model services, aggregators or gateways: none. Calinator uses no AI aggregator, gateway, model hub or endpoint.

4. Self-hosted or offline models: none. Calinator contains no AI or machine-learning model, cloud or local.

Calinator is a calendar app for the Linux terminal. It only shows the user's calendars and syncs the changes the user makes. It has no servers of ours, so Google user data never reaches us either.

A likely source of the confusion: our privacy page at https://stevinator.com/privacy/ covers all apps by the same developer. Other apps on that page (mainly TopDeck, a separate macOS app) do offer AI features and name AI providers such as OpenRouter, OpenAI and Anthropic. None of that applies to Calinator. To make this clear, the Calinator section now states it directly: https://stevinator.com/privacy/#calinator ("No AI. Calinator contains no AI or machine-learning features. It uses no AI model, cloud or local, and it never sends Google user data, or any data derived from it, to an AI service or to anyone else."). The Calinator homepage FAQ says the same: https://stevinator.com/apps/calinator/

Calinator's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
