Thank you. I have audited Calinator (project calinator, number 104932519162) against the checklist and confirm it meets the requirements. Details:

Scopes and justification
- Calinator requests only: calendar.events (sensitive), calendar.calendarlist.readonly, openid and userinfo.email. These exactly match the scopes configured in the Cloud Console and requested by the app. No restricted scopes, so CASA does not apply.
- calendar.events: the app shows the user's events and saves the events the user creates, edits, moves or deletes in Calinator back to Google Calendar (two-way sync), and sends the user's answers to invitations. Read-only scopes are not enough because editing and syncing back is the core feature. calendar.events.owned is not enough because users must also answer invitations to events organized by other people. The full calendar scope is not requested because Calinator never creates, changes or deletes calendars.
- calendar.calendarlist.readonly: shows the user's calendars (name, color) so they can choose which to show and where new events go.
- openid / email: shows which Google account is connected and finds the user's own answer in invitations.
- All scopes are used by production, user-facing features.

App access
- Calinator is an installed desktop app for the Linux terminal (OAuth installed-app flow with PKCE and a loopback redirect). It has no login of its own, no test account is needed, and there are no phone, payment or other blockers. The entry point is: press "@", choose "Google", and sign in in the browser, as shown in the video.

Privacy policy: https://stevinator.com/privacy/#calinator
- It states which Google user data is accessed, how it is used, that it is shared with no one (data goes only between the user's computer and Google; we run no servers), how it is protected (HTTPS, OAuth with PKCE, token in the system keyring, local file readable only by the user), and how long it is kept and how to delete it.
- It includes the Limited Use statement. Google user data is not used for advertising, not sold or transferred to third parties, and not used to develop, improve or train AI/ML models; Calinator does not send it to any AI service.
